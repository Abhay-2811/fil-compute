# fil-compute Docs

Compute-to-data on PDP/Filecoin: run jobs where data already lives, pay via escrow, and deliver results to user-controlled storage.

## Live deployment for hackathon testing

- Core API: `https://core.abhayu.com`
- PDP endpoint: `https://pdp.abhayu.com`
- Default PDP provider id: `22`
- These endpoints are available for trying `fil-compute` until the end of the hackathon.
